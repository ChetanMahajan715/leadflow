# Icons

Line icons, 24px grid, 1.75px stroke, round caps and joins, drawn in `currentColor` so they take the text colour around them. Use at 16px beside text and 20px inside buttons; inline the SVG (not `<img>`) when it should recolour.

`bell` today's follow-up · `alert` overdue · `calendar` scheduled follow-up · `clock` time since last note · `phone` phone number · `building` company · `note` discussion · `pin` pinned section · `plus` add · `search` search by name · `filter` filters · `close` dismiss.

Need another? Draw it on the same grid and stroke, or take the matching icon from Lucide, whose style is close.
