# Logos

- `leadflow-mark.svg`: the rising-wave mark in a Flow Teal tile. Favicon, app icon, compact header.
- `leadflow-wordmark.svg`: mark plus "LeadFlow" for light backgrounds ("Lead" in ink, "Flow" in brand).
- `leadflow-wordmark-dark.svg`: the same for dark backgrounds (`surface` dark), with the tile in dark-theme brand.
- `leadflow-mark-mono.svg`: the wave alone in `currentColor`, for one-colour use.

The wordmark's text uses Plus Jakarta Sans; load the font on the page, or convert the text to outlines before using it elsewhere. Keep clear space of half the mark's height. Don't stretch, recolour or add effects.
